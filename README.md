# R26-IT-024

# AI-Based Mangrove Conservation Decision Support System Using Remote Sensing, GIS, and Explainable AI

## 📌 Project Overview

Mangrove ecosystems play a critical role in protecting coastal environments, supporting fisheries, storing carbon, and maintaining biodiversity. However, mangrove forests are increasingly threatened by climate change, environmental stress, and human activities.

This research project aims to develop an AI-powered decision support system for monitoring mangrove ecosystem health, detecting environmental changes, analyzing impacts, and predicting future trends using Remote Sensing, GIS, Machine Learning, and Explainable AI techniques.

The study primarily focuses on the Puttalam District in Sri Lanka as the selected case study area.

---

# 🎯 Main Objectives

- Monitor mangrove ecosystem health using satellite imagery
- Detect temporal and spatial mangrove changes
- Predict future mangrove ecosystem trends
- Analyze fisheries-related environmental impacts
- Estimate blue carbon sequestration and valuation
- Support conservation decision-making through GIS-based visualization dashboards
